Import your data

Coming from another app, a spreadsheet, or a paper diary? Here's the fastest way to bring your history into TrackDX.

TrackDX can import a spreadsheet of your history, but it needs the data laid out in a specific way — one row per day, organized by condition. Reformatting old records by hand is tedious, so instead we give you a template and a ready-made prompt for Claude, the AI assistant, to do the reformatting for you in a couple of minutes.

This works for both kinds of condition TrackDX tracks: episodic ones that come and go in discrete attacks, like migraine or seizures, and daily ones that are present most days and you rate by body location, like sciatica or arthritis. You don't have to work out which is which — the prompt asks Claude to decide from your data and tell you what it chose. One workbook can hold a mix of both.

How it works

  1. Download the TrackDX Import Assistant. It's a workbook with worked examples and blank templates for both kinds of condition, a format guide, and a ready-to-use prompt — grab it below.
  2. Gather your existing data. Export a CSV from your old app, or just use whatever spreadsheet, notes, or paper diary you already have.
  3. Open a new chat at claude.ai. Any recent Claude model works well for this.
  4. Attach both files — your existing data and the Import Assistant workbook — then copy and paste the prompt below into the chat.
  5. Download the file Claude gives you back. It'll already be laid out in TrackDX's format. Skim Claude's summary of any judgment calls it made.
  6. In TrackDX, go to Me → Import history from .XLSX and choose that file.

Prompt for Claude 
I'm moving my personal health-tracking data into an app called TrackDX. I've attached two files:

1. My existing data — my history from another app, a CSV export, or notes I've typed up describing my symptoms, triggers, and medications.
2. "TrackDX Import Assistant.xlsx" — a workbook with a "Format Guide" tab (explains every column), worked examples, blank templates, and templates for the extra sheets.

FIRST, decide how each of my conditions is tracked. TrackDX supports two kinds, and they use DIFFERENT column layouts:

- EPISODIC — the condition comes and goes in discrete attacks. Migraine, seizures, cluster headaches, gout flares. My data will show individual events with a start time, or a "did it happen today?" flag, and long stretches with nothing.
- DAILY — the condition is present most days and I rate how bad it is. Sciatica, arthritis, neuropathy, fibromyalgia, chronic back pain. My data will show a severity number on most days, often broken down by body location.

Rule of thumb: if my data has a pain or severity score on most days, it's DAILY. If it records separate attacks with gaps between them, it's EPISODIC. Tell me which you chose for each condition and why. If I have both kinds, put each condition on its own sheet in the correct layout — one workbook can hold a mix.

Then convert my data. For BOTH kinds:

- Create ONE sheet per condition, named with the condition's name (max 15 characters — that's Excel's tab-name rule TrackDX follows).
- ONE ROW PER CALENDAR DAY, from the earliest date in my data through today, INCLUDING days with nothing logged. The empty days are real information to TrackDX's statistics, so don't skip them.
- PUT THE COLUMN HEADERS IN THE VERY FIRST ROW of each sheet. No title, caption or blank row above them — TrackDX reads row 1 as the header and stops, so anything above it makes the whole sheet import as empty.
- Date format must be YYYY-MM-DD. Times must be HH:MM in 24-hour format.
- Don't add columns of your own, and don't keep unmapped fields "just in case" — anything outside the layouts below is ignored on import.
- Delete the template's example rows before handing the file back.

=== EPISODIC LAYOUT ===
Columns, in this order: Date, Episode Occurred, Episode Count, Triggers Logged, Trigger Start Time, Trigger End Time, Drinks, Drink Type, then a repeating group of 8 columns per episode (Episode 1 Start Time, Episode 1 End Time, Episode 1 Duration (h), Episode 1 Intensity (1-10), Episode 1 Relief Medication, Episode 1 Relief Helped, Episode 1 Suspected Cause, Episode 1 Notes — then Episode 2 …, Episode 3 …, if more than one episode ever happens on the same day).

- "Episode Occurred" is 1 if any episode happened that day, else 0. "Episode Count" is how many.
- "Episode X Relief Medication" can list SEVERAL medications separated by "; " (e.g. "Excedrin; Maxalt"). Only medications taken to relieve that episode — preventatives go on the Med Periods sheet.
- "Episode X Relief Helped" is 0–10 for how much it helped: 0 = not at all, 10 = completely resolved. One score per medication in the SAME ORDER, separated by "; " (e.g. "4; 9"). Convert whatever my data uses: a percentage divides by 10 (80% → 8); "Yes"/"Somewhat"/"No" become 10/8/0; a 1–5 scale multiplies by 2. Tell me which conversion you used.
- "Episode X Intensity (1-10)" is 1–10; convert other scales proportionally and say how.
- "Episode X Notes" is optional free text about that specific episode. Keep it short; don't invent notes.
- A row with intensity 0 and no episode is NOT an episode. Many trackers record 0 or blank on symptom-free days — leave the episode columns blank and set "Episode Occurred" to 0. Such a day can still be a trigger day, so keep its Triggers Logged and Drinks values.

=== DAILY LAYOUT ===
Columns, in this order: Date, Triggers Logged, Trigger Start Time, Trigger End Time, Drinks, Drink Type, then one "Severity: <location>" column per body location I track, then Notes.

- The "Severity: " columns are what tell TrackDX this is a daily condition, so the spelling matters exactly — "Severity: Lower back", "Severity: Left calf". There is no "Episode Occurred" or "Episode …" column on a daily sheet at all.
- MAXIMUM 6 locations. If my data has more, pick the 6 most frequently recorded and tell me which you dropped.
- If my data records only one overall score with no body locations, use a single column named "Severity: Overall".
- Severity values are 0 to 10, in steps of 0.5. Convert other scales proportionally and tell me how.
- CRITICAL — blank and 0 mean different things and must not be swapped. A BLANK cell means "not recorded that day". A 0 means "I recorded it, and there was nothing there". Never fill a missing day with 0, and never blank out a genuine recorded 0. If my source can't distinguish them, leave it blank and tell me.
- "Notes" is optional free text for that day.

=== EXTRA SHEETS (add these when the data supports them) ===

"Conditions" — one row per condition. Columns: Condition, Tracking Mode, Sites.
- "Tracking Mode" is the word "Daily" or "Episodes".
- "Sites" is the full list of body locations for a daily condition, separated by "; " — in the order I'd want them shown. Include locations even if they were rarely recorded, so none get lost. Leave blank for episodic conditions.
- Include this sheet whenever any condition is daily.

"Procedures" — surgeries, injections, blocks, ablations. Columns: Condition, Procedure, Date, Site, Notes, Recalled Overall, Recalled By Site.
- One row per procedure. "Site" is the body location it targeted, if any.
- "Recalled Overall" and "Recalled By Site" are ONLY for a procedure that happened BEFORE my logging starts, where I've told you my remembered severity beforehand. "Recalled By Site" format is "Location=Value; Location=Value" (e.g. "Lower back=7; Left calf=5").
- Do NOT estimate or invent these. Leave them blank unless I explicitly gave you remembered numbers — TrackDX labels anything derived from them as recalled rather than recorded, and a made-up baseline would silently distort how well a procedure appears to have worked.

"Med Periods" — which preventative medications I was on, and when. Columns: Condition, Medication, Start, End (blank End = still taking it).
- Preventative medication history goes here, never in the daily columns.

When you're done, give me the finished file as a downloadable .xlsx, and summarize the tracking mode you chose per condition, any scale conversions, and any judgment calls — so I can review before importing.
